# CARION / ქერიონი — Auto Detailing Website

Demo website for **CARION / ქერიონი**, a car detailing studio in Varketili, Tbilisi.

**Live:** https://abrama1.github.io/carion-detailing/

## Features

- Bilingual: Georgian (default) / English toggle, persisted in `localStorage`
- WhatsApp booking: pick services, car, date and time — opens WhatsApp with a prewritten message (+995 577 77 58 92)
- Dark premium design built around the studio's black & gold branding
- Fully responsive, no build step — plain HTML/CSS/JS
